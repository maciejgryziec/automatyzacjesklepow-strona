wFirma jako część procesu księgowego

Przy wFirmie integracja nie kończy się na samym utworzeniu dokumentu. Trzeba ustalić, który użytkownik API wykonuje operację, jakie ma uprawnienia i jak dokument ma przejść dalej do KSeF. To szczególnie ważne wtedy, gdy sklep, Allegro i księgowość mają działać jako jeden kontrolowany przepływ.

API wFirma pozwala pracować m.in. z fakturami roboczymi i obsługą numerów KSeF, ale konfiguracja musi odpowiadać rzeczywistym uprawnieniom użytkownika. Dlatego pierwszym krokiem nie jest „podłącz token”, tylko rozpisanie: kto wystawia dokument, z jakiego kanału pochodzą dane i kto odpowiada za wysyłkę do KSeF.

Najważniejsze przy wFirma: użytkownik API i KSeF

Dokumentacja wFirma zwraca uwagę, że faktury tworzone przez API są przypisywane do użytkownika, którego dane autoryzacyjne wykorzystuje integracja. Przy automatycznej obsłudze KSeF właśnie ten użytkownik musi mieć poprawnie skonfigurowane uprawnienia i certyfikaty. Źle ustawiony dostęp może więc wyglądać jak „awaria integracji”, mimo że problem leży w autoryzacji.

W praktyce testuję cały scenariusz: dokument powstaje z danych sprzedaży, trafia do właściwego miejsca, KSeF przyjmuje go zgodnie z konfiguracją, a numer/status wraca tam, gdzie zespół może go później znaleźć.

Dokumentacja producenta: API wFirma · integracja wFirma z KSeF.

Co dostajesz

Jeden most, od początku do końca: analiza tego, jak sprzedajesz, budowa połączenia, testy na prawdziwych zamówieniach, instrukcja. Cena stała z cennika — integracja systemów od 2 900 zł; dokładna cena i termin zależą od API, liczby kanałów i obsługi wyjątków.

Najczęstsze pytania

Co trzeba przygotować po stronie wFirma?

Na pierwszym etapie wystarczy informacja, jakie dokumenty mają powstawać i kto w firmie odpowiada za księgowość. Dostęp API i użytkownika technicznego konfigurujemy dopiero wtedy, gdy znamy zakres; przy KSeF dodatkowo sprawdzamy wymagane uprawnienia i certyfikaty.

Sprzedaję też na Allegro. Czy te zamówienia też trafią do wFirmy?

Tak — to najczęstszy wariant. Zamówienia z Allegro i ze sklepu wpadają do jednej numeracji, bez podwójnego fakturowania tego samego klienta.

Czy numer KSeF może wrócić do procesu sklepu?

Jeżeli potrzebujesz takiej kontroli, integracja może sprawdzać wynik operacji i zapisywać identyfikator lub status przy powiązanym zamówieniu. Zakres zależy od tego, gdzie Twój zespół później szuka informacji o dokumencie.

Co jeśli coś się zepsuje za pół roku?

Integracje psują się po cichu — wygasa token, dostawca coś zmienia. Dlatego oferuję opiekę miesięczną: integracja może być monitorowana cyklicznie, a po wykryciu problemu dostajesz alert. Częstotliwość monitoringu i zakres obsługi awarii zależą od wybranego pakietu.

Ile trwa wdrożenie?

Prostszy zakres zwykle można uruchomić od około 10 dni roboczych. Dokładny termin zależy od API, liczby kanałów i wyjątków; testy na prawdziwych zamówieniach są częścią wdrożenia.

Co podać na start?

Wystarczy sklep i kanały sprzedaży, informacja kto dziś wystawia dokumenty w wFirma oraz jak wygląda obsługa KSeF. Nie wysyłaj kluczy API ani certyfikatów w pierwszej wiadomości.
